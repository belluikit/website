Everything you put in a window is a **canvas object**: a value that
implements [`core.CanvasObject`](https://pkg.go.dev/github.com/belluikit/bellui/core#CanvasObject).
A button, a container full of widgets and a plain rectangle all implement it,
so any of them can go anywhere another one can.

## The CanvasObject interface

A canvas object has a size, a position, a minimum size and a visibility:

| Method | Meaning |
| --- | --- |
| `MinSize() geo.Size` | The smallest size the object can be drawn at |
| `Size()`, `Resize(geo.Size)` | The current size |
| `Position()`, `Move(geo.Position)` | The top-left corner, relative to the parent |
| `Show()`, `Hide()`, `Visible()` | Visibility |
| `Refresh()` | Redraw the object after you change it |

Inside a container you rarely call `Resize` or `Move` yourself. The
container's [layout](/docs/layout/) does that, using each child's `MinSize`.

Sizes and positions are [`geo.Size`](https://pkg.go.dev/github.com/belluikit/bellui/geo#Size)
(`Width`, `Height`) and [`geo.Position`](https://pkg.go.dev/github.com/belluikit/bellui/geo#Position)
(`X`, `Y`), both `float32`. Create them with `geo.NewSize(w, h)` and
`geo.NewPos(x, y)`. They have helpers such as `Add`, `Subtract`, `Max` and
`Min`. A movement, such as how far a drag went, is a
[`geo.Delta`](https://pkg.go.dev/github.com/belluikit/bellui/geo#Delta)
(`DX`, `DY`).

## The canvas primitives

The [`canvas`](https://pkg.go.dev/github.com/belluikit/bellui/canvas)
package holds the basic drawing objects. They draw something and do nothing
else: they do not respond to input. To make something interactive, use a
widget or [build one](/docs/custom-widgets/) from these primitives.

{{< example file="concepts/canvas/main.go" region="shapes" >}}

| Type | Created with | Notes |
| --- | --- | --- |
| [`Text`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#Text) | `NewText(text, color)` | A string drawn in one style, with no wrapping or formatting. Set `TextSize`, `TextStyle` (bold, italic, monospace) and `Alignment`. For text that wraps or can be selected, use `widget.Label`. |
| [`Rectangle`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#Rectangle) | `NewRectangle(color)` | `FillColor`, `StrokeColor`, `StrokeWidth`, and `CornerRadius` (or one radius per corner). |
| [`Circle`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#Circle) | `NewCircle(color)` | Fills its bounds. `FillColor`, `StrokeColor`, `StrokeWidth`. |
| [`Line`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#Line) | `NewLine(color)` | Runs from `Position1` to `Position2`. `StrokeColor`, `StrokeWidth`. |
| [`LinearGradient`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#LinearGradient) | `NewHorizontalGradient`, `NewVerticalGradient`, `NewLinearGradient(start, end, angle)` | Set `Stops` for more than two colours; it then replaces the start and end colours. |
| [`RadialGradient`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#RadialGradient) | `NewRadialGradient(start, end)` | From the centre outwards. |
| [`Image`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#Image) | `NewImageFromResource`, `NewImageFromFile`, `NewImageFromURI`, `NewImageFromReader`, `NewImageFromImage` | Bitmap or SVG. See [Resources and images](../resources/). |
| [`Raster`](https://pkg.go.dev/github.com/belluikit/bellui/canvas#Raster) | `NewRaster`, `NewRasterWithPixels`, `NewRasterFromImage` | Pixels generated by your function at the size it is drawn. |

An image picks how to fill its space with `FillMode`:
`ImageFillStretch` (the default, ignores the aspect ratio),
`ImageFillContain` (fits inside, keeps the aspect ratio), `ImageFillCover`
(fills the space and crops) or `ImageFillOriginal` (asks for the image's
pixel size as its minimum size).

paths and box shadows. See the
[package reference](https://pkg.go.dev/github.com/belluikit/bellui/canvas).

### Minimum size of a primitive

Most primitives have a minimum size of 1×1 unless you set one with
`SetMinSize`. `Circle` and `Line` have no `SetMinSize` and always report
1×1. `Text` is the exception the other way: its minimum size comes from its
text and font size, and `SetMinSize` does nothing. In
a layout that sizes children by their minimum, such as a
[VBox](/docs/layout/containers/#vbox-and-hbox), a rectangle with no minimum
size is one unit tall and almost invisible. Either call
`rect.SetMinSize(geo.NewSize(w, h))`, or put it in a layout that stretches
its children. The full example uses
[`NewGridWrap`](/docs/layout/containers/#gridwrap) to give each primitive a
fixed cell:

### Changing a primitive

The fields of a primitive are plain struct fields. After you change one, call
`Refresh()` on the object so it is drawn again. Do both on the
[UI thread](../ui-thread/); the clock example on that page changes a
`canvas.Text` this way.

## Widgets are canvas objects

A widget is a canvas object with behaviour. The
[`core.Widget`](https://pkg.go.dev/github.com/belluikit/bellui/core#Widget)
interface adds one method to `CanvasObject`: `CreateRenderer()`. The renderer
it returns holds the primitives that draw the widget, and lays them out. That
is why a widget can sit next to a rectangle in any container:

Widgets that respond to input also implement interfaces from the
[`event`](https://pkg.go.dev/github.com/belluikit/bellui/event) package; see
[Input events](../input-events/). To write your own widget, see
[Custom widgets](/docs/custom-widgets/).

## Containers are canvas objects

A [`bellui.Container`](https://pkg.go.dev/github.com/belluikit/bellui#Container)
holds a list of child objects and a layout that positions them. It is a
canvas object too, so containers nest. See [Layout](/docs/layout/).
