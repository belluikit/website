## Report a bug or request a feature

Open an issue on the repository the problem is in. Most issues belong on
[belluikit/bellui](https://github.com/belluikit/bellui/issues), the toolkit
itself. The supporting libraries, such as [webgpu](https://github.com/belluikit/webgpu),
[glfw](https://github.com/belluikit/glfw) and [goffmpeg](https://github.com/belluikit/goffmpeg),
each have their own tracker. If you are not sure where something belongs, file
it on bellui.

A good report says:

- the Bellui version (`go list -m github.com/belluikit/bellui`) and your Go version;
- the operating system, and whether you built with the default WebGPU renderer or with `-tags gl`;
- the smallest program that shows the problem;
- what you expected, and what happened instead, including any panic or log output.

## Security issues

Do not report security problems as public issues. Use GitHub's private
vulnerability reporting on the affected repository instead; for the toolkit
that is [belluikit/bellui security advisories](https://github.com/belluikit/bellui/security/advisories/new).
The report stays visible only to you and the maintainers until a fix is out.

If you cannot use GitHub, email [bellui@trendvidia.com](mailto:bellui@trendvidia.com)
with enough detail to reproduce the problem.
